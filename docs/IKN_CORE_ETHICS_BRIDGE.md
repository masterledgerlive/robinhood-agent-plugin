## CORE (true for us)

From IKN prime insight and Solid extension — applied here as ethics, not as a protocol implementation:

1. **Truth has a shape we can address.** Same verified outcome → same id. Practical coordinates today: `path_id` + `trick_id` + real `order_id`.
2. **Proof before permanence.** Never invent PnL, fills, or “leader” success rates. Unverified agentic chatter stays in **Wild West quarantine** until ledger-proven.
3. **Gas-gated injection ≡ LOW_CAP_SLOW edge gates.** Only act when cost is justified (spread ≤0.8%, edge ≥2× RT). Low consensus / no edge → stay quiet. Motion ≠ mandate.
4. **Sovereignty.** Game owns the book and authorizations; agents trail and report; no silent risk widening.
5. **Open / forkable.** MIT plugin + plain-text machine view — library grows when others build; no proprietary lock for the trail model.
6. **Agents as library nodes.** Code watches continuously; Agentic step-in only on alerts — conserve usage the way IKN avoids parsing the whole internet.
7. **House vs catalog.** Robinhood holds the positions (house). Our success ledger / follow-paths are the card catalog of *what worked*. IKN Network Project is the bridge level across systems.
